# myjobpage — 스탠다드 뱅크 인증 프로젝트 대시보드

> 교육용 가상 데이터 기준 — 실제 업무 시스템 아님

인증 프로젝트 접수·진행현황을 보는 Streamlit 대시보드입니다.

## 주요 기능
- 기준일(기본 2026-10-23) 기준 잔여일수·일정상태(완료 / 지연 후보 / 오늘 마감 / 진행 예정 / 일정 확인 필요) 계산
- 사이드바 다중 선택 필터(시험분야·적용규격·담당엔지니어·진행상태·시료상태)
- 요약 카드, 시험분야별 막대그래프, 진행상태 비율 도넛 차트, 지연 후보 강조
- 시험분야 카테고리 관리(등록 / 이름 변경 / 사용 중이면 재분류 후 삭제)
- 전체·필터 결과 Excel 다운로드(프로젝트목록 / 상태별집계 / 담당자별집계 / 분석조건 시트)
- 의뢰 상세조회와 메모 수정, 시험 자원(EMC 챔버·RF 차폐실) 상태 카드

화면에서 바꾼 내용은 브라우저 세션(session_state)에만 보관되며, 원본 CSV는 변경되지 않습니다.
메일 발송이나 외부 시스템 연동 기능은 없습니다.

## 실행 방법
```
pip install -r requirements.txt
streamlit run app.py
```

## 데이터
`data/` 폴더의 CSV를 읽습니다. 파일이 없으면 화면에서 CSV를 업로드할 수 있습니다.
- `SB_project_demo.csv` (또는 `SB_projects_demo.csv`): 의뢰 목록
- `SB_resource_demo.csv` (또는 `SB_resources_demo.csv`): 시험 자원 상태
